This article is a living reference for every block-level and inline element available when authoring MDX articles in this codebase. Use it as a copy-paste source when writing complex pieces.

## Headings & Inline Formatting

Standard markdown is fully supported. Inline elements: **bold**, *italic*, `inline code`, [external links](https://optimize.deals), [internal anchors](#headings--inline-formatting), and combinations like ***bold italic***. You can also chain inline code with bold like `useEffect` **must** include a dependency array.

Use the <Kbd>Cmd+K</Kbd> shortcut to open command palette, or <Kbd>Ctrl+Shift+P</Kbd> on Windows. <Badge>new</Badge> <Badge variant="success">stable</Badge> <Badge variant="warning">beta</Badge> <Badge variant="error">deprecated</Badge> are inline badges.

## Code Blocks

Fenced code blocks are syntax-highlighted server-side via Shiki. Languages supported include `ts`, `tsx`, `js`, `jsx`, `bash`, `json`, `css`, `html`, `python`, and many more.

```ts
import { compileMDX } from "next-mdx-remote/rsc";

export async function render(source: string) {
  const { content } = await compileMDX({ source });
  return content;
}
```

You can also add a title via meta:

```tsx title="components/example.tsx"
export function Example({ name }: { name: string }) {
  return <div className="text-[#3B80EC]">Hello, {name}</div>;
}
```

Bash commands:

```bash
pnpm install
pnpm dev
git commit -m "feat: ship new feature"
```

For richer code presentation with custom filename and metadata, use the `<CodeBlock>` component directly:

<CodeBlock language="ts" filename="lib/example.ts">
{`export const config = {
  cache: 60,
  revalidate: false,
};`}
</CodeBlock>

## Putting It Together

Here is a realistic mixed section combining several primitives. It models a typical "performance optimization" walkthrough:

<Callout type="performance" title="Goal">
  Reduce LCP by deferring non-critical JavaScript and inlining the hero image.
</Callout>

<Steps
  steps={[
    {
      title: "Audit current performance",
      description: "Run Lighthouse against production. Capture LCP, FID, and CLS as baseline numbers.",
    },
    {
      title: "Identify the LCP element",
      description: "In Chrome DevTools → Performance → LCP marker. Usually the hero image or above-the-fold text.",
    },
    {
      title: "Apply targeted fixes",
      description: "Preload the LCP image, defer below-fold JS, and convert to AVIF if the browser supports it.",
    },
  ]}
/>
