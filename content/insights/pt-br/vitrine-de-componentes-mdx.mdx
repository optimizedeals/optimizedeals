## Cabeçalhos e formatação inline

Markdown padrão é totalmente suportado. Elementos inline: **negrito**, *itálico*, `código inline`, [links externos](https://optimize.deals), [âncoras internas](#cabecalhos-e-formatacao-inline), e combinações como ***negrito itálico***. Também é possível encadear código inline com negrito como `useEffect` **precisa** incluir um array de dependências.

Use o atalho <Kbd>Cmd+K</Kbd> para abrir o command palette, ou <Kbd>Ctrl+Shift+P</Kbd> no Windows. <Badge>novo</Badge> <Badge variant="success">estável</Badge> <Badge variant="warning">beta</Badge> <Badge variant="error">depreciado</Badge> são badges inline.

## Blocos de código

Blocos de código com cercas têm syntax highlight server-side via Shiki. Linguagens suportadas incluem `ts`, `tsx`, `js`, `jsx`, `bash`, `json`, `css`, `html`, `python` e muitas outras.

```ts
import { compileMDX } from "next-mdx-remote/rsc";

export async function render(source: string) {
  const { content } = await compileMDX({ source });
  return content;
}
```

Também é possível adicionar um título via meta:

```tsx title="components/example.tsx"
export function Example({ name }: { name: string }) {
  return <div className="text-[#3B80EC]">Hello, {name}</div>;
}
```

Comandos bash:

```bash
pnpm install
pnpm dev
git commit -m "feat: ship new feature"
```

Para uma apresentação de código mais rica com nome de arquivo e metadados customizados, use o componente `<CodeBlock>` diretamente:

<CodeBlock language="ts" filename="lib/example.ts">
{`export const config = {
  cache: 60,
  revalidate: false,
};`}
</CodeBlock>
